Experiment 03 / Graph — Minimum Spanning Tree

Kruskal's vs. Prim's Algorithm

Aim: connect every vertex in a weighted graph using the cheapest possible set of edges, with no cycles. Kruskal's works globally — sort all edges, greedily add the cheapest one that doesn't create a cycle. Prim's works locally — grow one connected tree outward, always adding the cheapest edge leaving the current tree.
